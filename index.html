Métricas de engenharia,
self-hosted.

Coleta GitLab e Jira para PostgreSQL, visualiza em Grafana. DORA, cycle time, throughput, code review. Roda 100% via Docker Compose, sem dependência paga.

Início rápido Ver dashboards GitHub ↗

QUICK START

# clona, configura, sobe
git clone https://github.com/alissonjr/dev-metrics.git
cd dev-metrics
cp .env.example .env  # preenche tokens GitLab e/ou Jira
make up               # http://localhost:3000

01

DORA & cycle time

Deploy frequency, lead time, MR cycle time, taxa de sucesso de pipeline. Por projeto e ambiente.

02

Kanban & sprint

Lead, cycle, action e awaiting time por issue do Jira. Throughput, WIP e burndown.

03

100% local

PostgreSQL, Grafana e 2 coletores Python sobem com um make up. Seus dados nunca saem da sua infra.
